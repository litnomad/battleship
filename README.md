## Battleship

The objective of this project is to create a battleship game where all ships must be hit. (see Odin Project curriculum: https://www.theodinproject.com/lessons/node-path-javascript-battleship)

## Objective
- To apply what I have learned about Test Driven Development throughout the development process to make sure that classes, methods, and functions were operating as they should for the game.

## Features
- Player against the computer
- Player places ships on the board
- Game over when all ships are hit
